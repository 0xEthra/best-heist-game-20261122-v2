# The Drowned Meridian — Best Heist Game
A stealth heist game built for the make.fun bounty "Make the best heist game".
## Play
Open `game/index.html` in Chrome (offline, no network). Steal the loot across 3 rooms, dodge guard vision cones and rotating cameras, keep the alarm below 100%, and reach the airlock.
## How it was built
Node 22 + vanilla JS/Canvas. Built by an AI agent with the make.fun kit.
